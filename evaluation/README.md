# Federated Conformance Checking Pipeline - Evaluation

## Getting started

The Event logs of Corradini et al. that were used for the evaluation must first be cloned from the COLLIERY Git repository.
To run the evaluation of the FCC Pipeline, follow the steps listed below:

- cd evaluation
- python evaluation_setup.py
- python run_evaluation.py 

All evaluation data for every log is stored in <log_name>/output (corradini/<log_name>/output)
